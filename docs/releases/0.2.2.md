# 0.2.2

## New mouse pointer

- The blue tactician pointer is replaced by a white pixel-art arrow with a dark
  plum outline that stays readable over grass, plains, forests and menus.
- The pointer is half its former size and is drawn at full display resolution,
  so it stays sharp on Retina and other high-DPI displays. It is the same size
  on the map, in menus and in dialogue, and no longer grows with map zoom.

## macOS interface polish

- Redesigned game library with a toolbar, an empty-library drop target, last
  played and save status per game, and Show Saves in Finder.
- Settings are organized into General, Video, Controls and Hotkeys tabs.
- A View menu holds the extended-renderer toggle, video shader presets and
  Adjust Shader…, which tunes the active preset's parameters live.

## Downloads

- **Windows x64:** Extract the ZIP and open `bin/fe8-mgba-sdl.exe`, then add
  your own `.gba` ROM and choose Play.
- **macOS arm64:** Apple Silicon application with its SDL runtime bundled.
  Extract the ZIP and move the app to Applications. Ad-hoc signed, not notarized.
- **Linux x86-64:** Built on Ubuntu 24.04. Install runtime dependencies with
  `sudo apt install libsdl2-2.0-0 libfreetype6 fonts-dejavu-core zlib1g`, then
  run `./fe8-mgba-sdl --rom /path/to/game.gba` from a graphical desktop.
- **Source with mGBA:** Includes the pinned emulator source.
- **SHA256SUMS.txt:** SHA-256 checksums for the four downloads.

No ROMs or game assets are included.
